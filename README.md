🌐 Modern AI-Powered Personal Portfolio

A sleek, dark-themed, high-performance personal portfolio website showcasing full-stack applications, computer vision tools, and IoT embedded systems projects. Fully optimized for security, accessibility (a11y), performance, and dynamic project filtering.

🚀 Live Preview: [https://my-portfolio-pied-phi-58.vercel.app](https://my-portfolio-pied-phi-58.vercel.app)

✨ Features & Optimizations

- Vibrant Dark UI: High-contrast, tech-focused design tailored for software and systems showcase.
- Dynamic Filtering System: Built with vanilla JS to filter projects instantly by categories (MERN, Java, PHP, Python, IoT).
- Comprehensive Code Audit Upgrades:
  - 🔒 Security: Hardened with `rel="noopener noreferrer"` across all external anchor targets.
  - ♿ Accessibility (a11y): Full semantic HTML layouts with updated `aria-pressed`, `aria-expanded`, and `aria-required` tags.
  - 📱 Mobile Touch UX: Custom `@media (hover: none)` fallbacks that adapt hover overlays into static layout components on mobile devices.
  - 🔍 SEO & Social Sharing: Pre-configured with Open Graph meta tags, canonical definitions, and tailored `theme-color` schemes.
    
🛠️ Tech Stack & Architecture

- Frontend: Vanilla HTML5, Tailwind CSS, JavaScript (ES6+)
- Hosting & Deployment: Vercel (Continuous Integration via GitHub)
- Design Assistance: Developed & audited using Antigravity AI IDE
  
📂 Project Showcase Overview

The portfolio programmatically mounts and handles various full-stack and engineering projects:

1. Sweet Delights — Full-stack MERN ERP Bakery Management System (Scrum/Jira workflow).
2. Part Time — Student employment gig marketplace utilizing React, React Native, and Firebase backend.
3. Property Sales Management System** — Desktop/Web-based Java architecture.
4. Air Drawing Project — Computer vision application powered by Python, OpenCV, and NumPy gesture tracking.
5. IoT Based Embedded System — Hardware orchestration and smart automation using ESP32 and C++.
